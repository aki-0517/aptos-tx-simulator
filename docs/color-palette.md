## Usage Guidelines
- **Primary brand colors**: Black, Aptos Blue, and White should be prioritized in all visual communications.
- **Secondary colors**: Can be used for additional needs such as charts, graphs, flow charts, and presentation decks.
- **Contrast rules**:
  - Aptos Blue text should **only** be used on **dark backgrounds**.
  - Do **not** use Aptos Blue text on **light backgrounds**.  
    → Use **Aptos Blue-Light (`#3EA2A8`)** instead for readability.
- Always ensure **sufficient contrast** for legibility and communication when pairing colors.
